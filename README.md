# 梦回1995 · 小村的夏天

糖果的游戏

独立怀旧童年游戏项目。当前版本：第20版（真人好友联机版）。

支持触屏摇杆、键盘、乡村探索、角色装扮、上学、种养、天气、小游戏及本地存档。

游戏资源位于 `docs/`，采用 GitHub Pages 发布。独立于数学课件与旧3D游戏维护。

游戏进度保存在玩家浏览器中；更换域名时可通过游戏的存档导出与导入功能迁移。

## 真人好友联机

主页选择“好友联机”，创建或加入 6–12 位数字密码房间。标准联机使用房间中转服务；直连为备选。房间仅支持两名玩家，位置、方向、装扮及击掌实时同步，每个人的存档和日常任务独立保存。后端源码与数据表定义见 `server/`，已部署的服务不需要玩家注册或登录。
